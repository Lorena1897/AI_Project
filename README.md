## Objetivo
Explorar las tendencias emergentes en IA utilizando GitHub Copilot como herramienta practica.

## Pasos realizados
1. Creacion de cuenta en GitHub y activacion de Copilot (plan gratis).
2. Creacion del repositorio `AI_Project` en GitHub.
3. Creacion del archivo `recommendation_system.py` con ayuda de GitHub Copilot.
4. Commit de los cambios al repositorio.
5. Documentacion del proceso en este README.md.

## Descripcion del codigo
El archivo `recommendation_system.py` implementa un sistema de recomendacion simple usando K-Nearest Neighbors (KNN) de scikit-learn. Carga datos, los divide en entrenamiento y prueba, entrena el modelo, evalua su precision y permite recomendar un producto segun sus caracteristicas.
